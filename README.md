# Common Ground — POLI 111 audiobook

A small, responsive political science study app designed for two people to read and discuss together.

## Features

- Eight original POLI 111 chapters, with a Ghanaian government focus.
- Browser text-to-speech, with voice and pace controls. Available voices depend on the device and browser.
- Two editable reader names and turn-taking.
- Two discussion questions after each chapter.
- Saved chapter progress in the current browser.
- Ghana News Agency brief, dated November 7, 2026, with links to the report and current politics desk.
- Source links alongside the lessons.

## Run it

Open `index.html` in a current browser. No build step or server is required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a repository for this app.
2. Add `index.html` and `README.md` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)` folder.
5. Save. GitHub Pages will show the published address in the Pages settings after deployment finishes.

The publishing session used for this handoff was signed out of GitHub, so no repository was created or uploaded from here.
